# 内容与语言

## 完整知识与阅读负担

保留整门课程的基础知识、推导和应用。以读者能够从头重新学习为标准，允许篇幅随课程范围增长。依知识关系组织完整分目，在分目内部使用必要的解释、定义、条件、公式、图解、小表格和例题步骤。保持分目之间的推理联系，避免碎片化的概念卡片。正文不再要求连续说明文。

每个概念至少考虑学习动机、定义、符号、适用条件、直觉、典型例子、必要推导和相关概念。按学科补充证明、过程、反例、因果论证或算法分析。主栏承担必要知识；副栏承担补充解释、提问、辨析和记忆提示。隐藏副栏后，主栏仍应足以理解本节。

一段通常承担一个解释任务，行数依必要解释与模板网格决定。2–5 行只可作为部分短段的观察值，不能据此删去逻辑或强制每个知识点独占一页。普通知识页应容纳数个完整且相关的分目，密度直接对照原书普通知识页；保持大学层次的推导、条件和应用深度。长证明可以用步骤名、方程和连接句分段。连续长段、重复开场白、抽象名词堆积、同义句反复说明会增加阅读负担。检查这些现象并写成具体解释。

完整例子交代变量、条件、计算和结论的意义。公式附近说明符号与使用前提。易混概念放在小对照表或图中，并保留解释差异的句子。不要用整段粗体代替组织知识。

## 直接讲解

**笔记中不得使用防御性表达。** 正文、标题、侧栏、图注和答案均直接讲知识、条件与推导。删除预防批评式免责声明、反复自我解释、无必要的软化或对冲、夸大读者误解的警告，以及对生成过程或文本取舍的辩护。不写“为避免误解先说明”“仅供参考”“这里并不是说”“为了保持严谨”等开场或免责段落，也不解释作者为什么这样写、为什么省略内容或为什么需要补充说明。

保留知识正确性必需的定理前提、变量范围、概率分母正值、模型假设、统计估计的不确定性，以及题目要求的比较和理由。将具体条件写在定义、公式、模型或结论附近；将不确定性写成其来源、范围或对结论的影响。例如直接写“当 P(B)>0 时，P(A|B)=P(A∩B)/P(B)”；直接写“该模型假设两次检测在给定实际状态后条件独立”；直接写“样本估计随抽样结果变化”。完整保留这些知识内容。

逐句判断表达承担的教学作用，不按词语黑名单删改。“不确定性”“假设”“条件”“一般”等可以是准确的学科表达；否定句、反例和概念比较可以承担必要推理。删除的是免责、辩护和多余铺垫。若一句话兼有有效知识与防御性铺垫，保留有效知识并直接陈述。交付前检查全部实际渲染文字，覆盖漫画对白、表格、图注和英文答案。

## 知识关系与反复阅读

维持先修知识顺序。小节之间说明新概念解决什么问题。后续知识使用旧概念时，可以用不同例子恢复必要基础。

章末“基础知识再读”包含关系图或整理表，以及能够恢复推理关系的短解释。支持多次通读的方式包括一致术语、明确条件、稳定编号、可查例子和完整答案。不要用重复原句充当复习设计。

主体篇幅优先基础知识，例题和扩展按学科需求安排。旧版说明、例题、扩展的百分比不再作为分页配额。不要为符合比例增加重复内容。

## 扩展中英术语

正文前设置足够完整的术语导读，条目统一采用“中文词汇＋英文对应＋中文解释”。先对照各节内容列出阅读所需术语，再确定条目数。覆盖基础概念、易混概念和专业表达；历史等学科还应纳入理解正文所需的组织、制度、人物身份和事件专名。十余页的实质性章节可以需要二十至三十项或更多，数量随实际知识范围确定；不得沿用六至十二项的上限，也不得只选少量熟悉词交差。

| 字段 | 内容 |
| --- | --- |
| 中文词汇 | 正文采用的规范中文名称 |
| 英文对应 | 标准英文名称、必要缩写与常见同义表达 |
| 中文解释 | 用中文说明含义、相关条件和本章中的作用，必要时说明与相邻概念的区别 |
| 英文用法 | 可补充本章语境中的完整英文例句或常见搭配，辅助后续英文作答 |

中文解释是必填内容，不能由英文定义、单词直译或英文例句代替。解释深度以读者能够继续阅读相关章节为准。条目多时增加术语页，保留每条内容的连贯性、正常字号与行距；不得为凑一页删去必要解释。首次出现处再放简短提示，完整条目与正文互相定位，全书收录索引。长解释放在主栏或术语专题页。自写英文采用澳大利亚拼写，原文引述保持原样。

## 例题与自测语言

示范例题可保留已有英文原题；面向英语考试的示范解答使用完整英语。解答包括方法、必要中间步骤、理由、结果和解释。保留定义域、量词、单位、代入过程，以及相关正确性、终止性、复杂度说明。中文直觉说明可以放在完整解答前后。

结尾自测、自查、各小问和“闭书回忆”使用中文提问，并逐题配完整英文答案，编号严格对应。该规则优先于英语考试练习的默认全英文规则，不得将自测题干改为全英文。定义题写定义与条件，计算题写代入和计算，证明题写完整论证，解释题写关系与原因。提示、答案关键词或“略”不能替代完整答案。答案可以紧随题目，也可以放在有明确页码的答案区。

## 答案词汇

完整英文答案之后设置独立的答案词汇区，允许占用多页。逐题阅读最终答案，收录理解和复述答案所需的学科词、核心动词、常用搭配及因果、比较、条件、证据与结论表达。覆盖各题和各答案分区，保留初学者容易卡住的表达，不能仅列四五个单词，也不能原样复制开头的名词表。

每项包含英文词汇或表达、中文含义或用法说明、来自本章语境的英文例句，以及相关题号。同一词在答案中的专门含义优先；需要时比较近义词或给出搭配。英文例句应说明怎样用于作答，不能只有孤立译词。所选词汇实际用于答案或直接帮助表达相应论点，避免用无关词扩充数量。

用户指定中文考试或其他语言政策时，以用户要求为准。

## 信息来源与书内内容

以提供的课程材料为主要知识来源。保留命名定理、定义和事实的来源意义。新增例题按教学用途编写，不伪装成原课练习。需要核实的事实使用主要来源，冲突在相关知识处说明。

书末可以有学习参考文献与术语来源。具体课件页码、制作流程、生图提示词、排版参数、模型声明和资源许可证不占用知识正文。资源许可证保留在制作文件中。

## 物理页底趣味条

每个正文内容页在物理页面最底部设置独立浅绿（#F3F7E0）横条，使用一至两行深色（#252823）文字放一则短笑话、趣味冷知识、学科知识或有出处的名言名句，连同必要署名最多两行。它是固定页家具，位于正文网格之外；不得放在页顶，也不得作为正文结尾的知识栏目、分区或内容块。采用模板规定的位置和容量，页码与趣味文字互不遮挡，打印版继续保留完全空白的装订边。

题材可以与课程无关，也可按学科筛选。使用[结构化趣味语料与抽取脚本](fun-content.md)，事实保留来源，名句保留作者和作品；不要把自行编写的励志句署给名人。默认生成时随机不重复抽取，目录、连续术语页、正文和答案词汇页共同去重，同一本书的各章共享已用记录。新增语料逐条阅读，避开性别歧视、政治冒犯或政治敏感、种族主义内容。封面、故意空白页和独立折页不放趣味条。

## 标题与句法

先实际查看四本原书的章名、节名、知识点名和栏目名，沿用它们以学科名词和简短栏目为主的命名方式。标题应直接说明知识对象，例：条件概率、乘法公式、全概率公式、贝叶斯公式、事件的独立性、典例精析、易错辨析。英文标题也使用标准知识名称。

标题使用一个知识词组或短句，不含逗号、冒号或问号；不使用“把……”句、“从……到……”句、教学口号、过程解说、反问或夸张命令。副标题、图表题、目录条目、页眉和PDF书签遵守同一规则。必要的数字编号与数学符号可保留。标题不得通过删除标点而留下拗口长句，应直接回到标准知识名称。

正文优先使用明确主语、直接动词和具体对象，避免把字句及无必要的动词名词化。例如“根据证据更新概率”优于“进行基于证据的概率更新”，“比较两个条件”优于“进行两个条件的比较”。固定数学术语保持规范，不为形式要求破坏“条件化”等确有学科意义的术语。少用“进行……的实现”“完成……的构建”“实现……的转化”等空泛结构。

交付前逐项检查标题标点、把字句、从…到…标题及抽象名词堆积。自动检索只提供候选，仍按句子实际语义判断；精确引用题干保持原意。
