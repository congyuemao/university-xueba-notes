# 内容与语言

## 写作目标

正文让读者学会辨认对象、解释关系、完成推理并使用知识。保留大学课程的定义、前提、证明、推导和应用深度；篇幅由讲解需要决定。参考书提供分目、图表与典例相邻的组织方式，大学课程材料决定知识内容。判断密度时数已经讲完整的知识单元，不数术语、公式或字数。

主栏承担核心定义和主推理；侧栏是第二教学通道，可承担补充辨析、小型图解、记忆关系、局部推导、条件和方法总结。必要例子不可仅存在侧栏。具体正反例见[教学改写样例](teaching-examples.md)。

## 首次教学怎样讲透

先确定核心概念与先修关系。核心概念是后续理解、推理或操作必须依赖的概念；单个日期、人名、已会的算术和辅助事实不必各写一套教学链。读者基础依用户或课程要求判断，不能默认为已经掌握本章要教的内容。

概念可先以introduced身份在导览或分类中出现名称；首次正式教学时才安排taught。章节编辑检查以下五项，不要求首次提名就同时展开：

| 教学任务 | 正文需要出现的内容 | 未完成的常见表现 |
| --- | --- | --- |
| 规范定义 | 对象、关系、范围及成立条件；符号首次出现即解释 | 只给术语的同义词，或用更多未解释术语定义它 |
| 通俗解释 | 明确究竟在数什么、比较什么、怎样变化或怎样判断 | 用“本质上”“直观来看”再复述一次定义 |
| 具体例子 | 可核对的数量、对象、过程、材料或图像 | “例如在实际生活中很常见”，没有实际内容 |
| 对应说明 | 例子的对象、数字、步骤分别对应定义的哪一部分 | 有表、有算式，但读者仍需自己猜分子分母或推理依据 |
| 条件与辨析 | 当前使用所需的边界、反例或相邻概念区别 | 只说“注意条件”“不要混淆”，没有具体条件或区别 |

通常按定义、解释、例子、对应、辨析展开；正式定义前可先给一个不用新术语的具体观察或数据情境。使定义或公式成立的条件必须随它出现，不能为遵守五项顺序而拖到最后。基础理解建立后，再讲少见边界和推广。

五项是章节内容检查项，不是五段连续文字或固定的五个标题。它们可分布于定义块、图、表、例题、手写箭头与侧栏；核心定义和主推理仍在主栏。短概念可以在一段和一幅图内完成，复杂概念可以跨几个相连分目。已经讲过的概念再次出现，只补当前推理所需的回顾。

### 控制一次需要理解的内容

- 一段承担一个主要任务。先讲对象，再讲关系，后讲推论；不要在一句中捆绑数个首次定义。
- 第一个具体例子或工作图出现前，通常只引入一至两个新抽象术语。定义确需更多先修词时，先用小例子讲清它们。
- 定义与代表性例子之间至多隔两个正文块；如果块很长，仍须按实际阅读距离调整。优先相邻，不用人为拆块来满足计数。
- 出现第三段连续抽象解释时，复查能否提前放入具体对象、代入或工作图。长证明可连续论证，但须先交代已知条件、待证结论，并解释关键推理依据。
- 同一个简单情境可以贯穿定义、公式和辨析，减少读者反复记忆背景。关系讲清后再换情境检验迁移。
- 短教学链尽量留在同页或同一展开面。页末放不下时移动整个短单元，或在续页交代正在处理的对象；保持可读字号与行距。

### 公式、推导和结果

每个首次公式都交代：适用情境，符号与单位或取值范围，各量的关系，计算或推导步骤，以及结果在原情境中的含义。同一组符号已在紧邻位置说明时不重复释义。

相邻两式之间写出发生了什么：代入哪个定义、使用哪个条件、合并哪一项、为什么允许相除或换序。不能用“显然”“易得”“整理可得”跳过本节读者尚未掌握的关键步骤。基础代数可以合并，但知识转换的理由必须保留。

比例说明所针对的群体和分母；平均量说明时间或范围；向量说明方向；实验说明变量、对照与观察；算法说明输入、状态变化和输出。结果既有数值或结论，也有对象、单位和解释。

### 不同学科怎样展开

| 学科任务 | 讲解需要接通的环节 |
| --- | --- |
| 数学与统计 | 具体对象 → 定义与符号 → 代入或证明 → 结果含义 → 适用条件与反例 |
| 物理 | 研究对象与所求量 → 模型及近似条件 → 图与方程 → 单位、方向和结果解释 |
| 化学 | 宏观现象 → 粒子或结构变化 → 符号表达 → 条件、守恒关系与证据 |
| 生物 | 结构或参与成分 → 过程先后 → 作用机制 → 可观察结果及适用范围 |
| 历史 | 时间、地点与行动者 → 材料中的具体事实 → 制度或行动如何起作用 → 结果与解释范围 |
| 计算机 | 问题与输入 → 状态及规则 → 小规模执行轨迹 → 输出、正确性和复杂度 |

这些是按任务选用的关系，不是每节都要填满的栏目。历史解释须区分材料直接记载、由材料支持的推断和存在争议的解释；生物机制与因果链须有来源依据，不能为讲得顺而补造中间环节。

## 防御性表达的处理

直接陈述知识、条件和理由。删除的是作者自保、写法辩护和提前回应虚构批评的句子，例如“为避免误解先说明”“这里只是帮助理解”“这并不意味着本书忽视严谨性”“限于篇幅不再展开”。正文无需评价自己的严谨、完整或通俗。

逐句辨别三种情况：

1. **只有免责或自我说明**：删除整句。删后检查前后衔接。
2. **铺垫后有有效知识**：留下知识，将对象、条件、结论直接写出。
3. **命题本身存在限制或不确定性**：保留，写清限制来自哪里、影响哪个结论。资料不足时如实说明具体缺口，不用肯定语气填补。

| 原表达 | 处理后的表达或动作 |
| --- | --- |
| 为了保持严谨，这里需要强调分母不能为零。 | 当 P(B)>0 时，P(A∣B)=P(A∩B)/P(B)。随后解释 B 是已知事件。 |
| 这只是一个便于理解的例子，不代表所有实际情况。 | 交代本例的具体设定，如“从这批组件中等可能抽取一件”。没有额外适用限制就删除原句。 |
| 不能简单地认为二者相同，需要具体情况具体分析。 | 指出比较的维度、各自条件和一个产生不同结果的例子。 |
| 这里并不是说小物体一定能看成质点。 | 判断质点模型能否使用，要看物体大小和形状是否影响所求量；接一个研究任务的对照例子。 |
| 这种结论可能在一定程度上受到多种因素的影响。 | 写出已有证据支持的影响因素及其作用；尚不能确定时说明哪项证据缺失。 |

必要的否定句、概念对照、反例、模型假设和统计不确定性都保留。“不一定”“通常”“在……条件下”可以有准确的学科含义；“不是……而是……”可以承担真实辨析。不能按词语黑名单批量删除，也不能把去防御性表达理解为去掉边界、夸大确定性或隐藏尚未完成的工作。

## 无信息语句的处理

每句话至少增加一种内容：事实、对象、关系、条件、理由、操作、例证、结论解释或必要的前后连接。逐句做删除检查：删掉后，读者能知道什么、能做什么、能跟上哪一步是否改变？三者都不改变时，优先删去。

| 无信息或低信息表达 | 应补上的内容 |
| --- | --- |
| 这个概念非常重要，是后续学习的基础。 | 指出后面哪一步要用它，以及怎样用；没有必要联系则删除。 |
| 我们需要理解其本质，建立正确认识。 | 写清正在研究的对象与关系。 |
| 结合实际情况进行具体分析。 | 指出要检查的变量、范围或条件，以及各条件对应的判断。 |
| 通过上述分析，我们可以更好地理解这个问题。 | 给出刚刚得到的具体关系；若与上一句重复则删除。 |
| 这体现了二者之间的密切联系。 | 写出联系的方向、机制或可计算关系。 |
| 这一变化产生了深远影响。 | 写出影响了谁、哪项行为或制度改变，以及材料如何支持。 |

同义复述不能冒充通俗解释。“条件概率是在条件下的概率”没有增加信息；“已知被标记后，只在被标记的组件中统计缺陷比例”给出了统计对象。

保留能帮助读者跟上推理的短句。例如“现在只看被标记的280件组件”虽然简短，却改变了计数范围；“前两式使用同一个分母，因此可直接相加”提供了运算理由。不能为了句句新知识而删掉这些连接。标题、图例和固定页底趣味条按自身功能判断，不按正文论证句的标准硬删。

## 自然中文与章节组织

使用具体主语和直接动词。专业术语保持一致，避免为了换词把同一个对象写成多个名称。短句交代判断，较长句解释原因；句长服从内容，不追求统一节奏。避免套话、无依据的意义拔高、连续排比、过度连接词及“进行……的实现”等名词堆叠。口语化不能变成卖萌、口号或故作亲切。

标题沿用标准知识名称和简短栏目名，如“条件概率”“物质的分类”“典例精析”。保留现行标题约定：不用把字句、从……到……句式、教学口号、逗号、冒号和问号。正文以直接表达为先；检查把字句和否定句时仍须看语义，不做机械字符串替换。原题及必要引用保持原意。

普通知识页承载若干相关的完整分目，也可由一个较长推导、计算例子和条件辨析组成。不能为“每页多个概念”硬塞首次定义，也不能把一个浅显区别拉长成整页。图、表、短解释和连续论证按知识关系组织，避免反复套用“标题加四段话加公式”。

章节衔接说明新问题从哪里来。章末综合可用关系图、对照表、时间线、反应网络或执行轨迹，并解释关键连线。复习通过稳定术语、明确条件、不同情境的应用和可回查的例子实现，避免重复原句填充篇幅。

## 侧栏、图表与词汇表

侧栏绑定具体主栏块，放在读者已读到相关说明的位置。所依赖的核心概念和符号须已在主栏讲过；不能仅因属于同一页就视为已教。必要例子和定义回到主栏，侧栏保留补充辨析、短路径和记忆线索。漫画用一个动作或关系帮助理解，气泡不只喊“别搞混”“记住它”。默认省略 `sidebar.keywords`，避免小词汇表重复正文。

图表给出可读标签，正文指出应观察哪一部分、该部分怎样支持当前结论。“见图”“如表所示”不足以解释。漫画、关系图和数据表各自登记教学作用。

中文讲解默认保留标准英文术语，可在首次定义旁出现。完整书末尾按章列专有词汇，每项只有 `term_en` 与简明 `meaning_zh`，最多加一个必要短限定。排除普通动词、连接语、单题措辞、英文例句和答题用途；按正文首次实质出现顺序排列。词汇表仅供查询，不计入首次教学完成情况。

## 典例、来源与交付前检查

典例包含条件、问题、方法选择理由、必要中间步骤、结果和情境解释。答案紧随问题或处于同一教学单元。默认不另设综合自测、独立答案页和答案词汇；用户要求练习系统时再建立。英语考试保留完整英语解答，中文直觉说明可相邻出现；用户指定语言时依其要求，原创英文采用澳式拼写。

以课程资料为主要知识来源，新增教学情境标为自编或在制作记录中登记，不能伪装成原题、史料或实验结果。必要引文与证据出处保留在相关位置，完整学习参考列于书末。制作流程、提示词、排版参数、审稿标签和资源许可留在制作资料中。页底趣味条遵循[趣味内容规范](fun-content.md)，不承担正文教学。

完成后逐个查看实际首次正式教学位置；主干据主栏、补充据侧栏分别核对读者能否回答：研究什么对象；符号表示什么；条件和范围是什么；例子怎样对应定义；步骤为何成立；结果表示什么；最易混淆的区别是什么。确实不适用的项目在制作记录注明原因，不为凑项增加公式或辨析。

再做两遍语言复核：第一遍删除作者自保与写法辩护，第二遍删除空泛评价、同义重复和无作用过渡。覆盖实际输出的主栏、侧栏、表格、图注、漫画对白及答案。只在概念元数据中写全、正文没有呈现，判为未完成；词语检索只能提供候选，不能自动判定教学合格。

## 学习版、知识块与边界分级

默认learning版支持从零学习；revision用于已学后的复习与速查，不能以固定页数压缩原教材的全部方法。每个单元先选表达：关系用图、分类用表、运算用步骤、算法用轨迹、应用用完整题目。定义/性质/规则/条件、短例题、比较、公式关系、易错、记忆和读图各有真实块类型；paragraph用于需连贯论证的内容。

A条件是首次使用必需的前提，紧贴公式或定义，如Dijkstra非负边权、M/M/1稳态条件、条件概率分母正值。B是常见考试/使用边界，可放后部或侧栏，如退化、多重最优。C是高级数值与工程问题，只在课程要求时进入主线，否则作为明确扩展或省略。保留正确性，避免每个概念都同时承受所有边界。

introduced只表示提名；taught须有实际五项教学证据。一个总览页可介绍名称并指向后文，不应为了覆盖章节概要完成十多个新定义。手写层只能加工已讲知识，不能抢先引入核心术语。

每个较大章节至少评估并安排一组典例精析/综合应用；短章可合并。完整题干、分析、过程、结果与方法总结属于正文教学，不等于默认自测。

每块记录source_kind。教材核心、课程核心、自编例、补充、编辑综合的边界见book-plan.md；自编章用附录或综合篇，不冒用教材章号。
