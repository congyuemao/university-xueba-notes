# 制作与四层检查

## 来源与校准

先实际看参考PDF图像。记录文件校验值、PDF物理页、书内页及查看方式。当前成品为诊断对象，两本数学笔记提供知识组织和视觉参考，教材决定课程内容。当前检查记录见[校准诊断](calibration-review.md)，历史观察不能替代新页实查。

每次大版本至少比较普通页、综合题、目录；仅在明确启用独立地图时比较地图。更新skill设计合同后，修改相关schema与renderer；只有视觉变更才修改母版；只在实际能渲染且有例页时宣称支持。三章校准先覆盖LP定义/图解/翻译表、单纯形表格轨迹/手写/典例、DP状态/递推表/应用。校准不意味着整书重做。

## 制作顺序

1. 定义learning/revision与print/digital两个维度，明确范围与先修。
2. 先看目录、地图、普通、题型、函数/三角/向量、统计、几何页，记录层次与侧栏分工。
3. 建立知识outline和source_kind，区分introduced与taught，规划A/B/C条件。
4. 为每个教学单元选择图、表、公式、步骤、例题或连续论证。五项教学检查分配到适合载体，主栏定义与主推理完整。
5. 作者按语境选局部荧光；手写层做已有知识的二次加工；侧栏安排第二教学通道。图表优先，漫画辅助。
6. 写入v2内容，核对teaching_refs实际指向。调用填充器，读取compiled及layout，修复溢出、锚点、目录、留白告警。
7. 检查最终导航、奇偶装订、双侧栏、页底趣味条与书末词汇表；渲染所有页。
8. 逐页语义复核、视觉复核后保存版本和验收记录，不重复使用旧样本“已通过”的结论。

字体由prepare_fonts.py准备，Body/Hand分开。新例页见Resources/content/operations-research-calibration.json及Resources/examples/calibration-*。旧statistics-chapter和print-reference/digital-reference保留为旧接口兼容样例，不证明新版教学效果。

## 四层记录

| 层 | 实际依据 | 不能替代的检查 |
| --- | --- | --- |
| automatic_structure | 唯一ID、层级、引用、来源映射、目录锚点、先修及页型 | 内容意义 |
| automatic_fields | 块所需字段、表格矩形、实际行高、锚点有效、图槽、留白面积 | 视觉相似度 |
| human_content | 逐页阅读正文和边栏、核对公式计算、单位、数字所指、教学链和来源身份 | 不能仅勾选concept字段 |
| human_visual | 每页渲染、阅读尺寸和局部放大、原版同类页并排检查 | 不能仅确认PDF文件存在 |

每项保存输入版本/哈希、输出哈希、页号/块ID、证据与结论：passed、needs_revision、not_run，确不适用为not_applicable并说明。自动生成layout的人工检查一律先为not_run；另写已完成的实际review记录，不由脚本冒签。

## 逐页与章节审稿

逐页检查连续文字墙、适合图表却仍是段落的内容、无解释作用的图、侧栏长期空置、手写连续缺失、主栏下半页和侧栏同时大空白。首先重排知识，不能靠漫画或放大空图填满。

逐章统计普通页、图解、完整典例、综合题、漫画、工作图、手写页比例、独立地图是否确有用户请求及教学价值。连续3–4页同结构时人工复查。脚本占位密度仅是提示；比较阅读节奏和信息密度须实际看图。

内容校验检查：定义、具体对象、符号、单位、条件、推理、结果意义及来源；例题是否完整；高级边界是否抢占首次学习；自编内容是否冒充教材章次。比如“每期订为120”须核对是件数还是三次开机费，不能因数字正确而放过指代。

侧栏核心定义不可独占，补充辨析/小图/局部推导允许；锚点位置必须在读者具备先修后。每章测量可写空间，不能用固定每页空白比例束缚图解页。

目录检查kind样式、父首子、栏平衡、尾页密度、相关插图、页码/链接/书签。默认没有独立地图页。获准启用时，再检查有机多级分枝与公式/图节点，不能仅是几列框。手写检查字体区别、箭头起终点、圈画位置、文字可辨，不遮公式。

## 最终输出

完整书的正文主线与条件正确，图表参与推理，正文/手写字体已嵌入，纯白纸面、蓝线与基线稳定，打印内侧20 mm空白、数字双侧栏存在，趣味条在275–285 mm。输出正常可检索PDF及用户所需源数据。

复核覆盖全部输出页；抽查仅能声明抽查范围。校准书是明确标注范围的样本，不可宣称完整Taha课程已重新生成。若仍有缺陷，给具体位置与状态；schema通过不能把人工检查变成passed。

## 语言与例题验收

1. 先整理私人短摘录与公开自编校准；再修改规范、必要schema与renderer，最后重排LP、单纯形、DP样稿。保留已校准的Body、Hand、侧栏和母版。
2. 自动检查worked_example结构、formula_step理由/公式、每步标题与内容；记录前文依赖词、多步连接词及实际段落行数。layout的language_findings保留页码/块ID/行数，区分warning与manual_review。
3. 首次教学抽查与连续三页阅读检查：完整句、自然连接、合理解释性重复；段落任务清楚，关键公式独立，步骤可定位；题框单独读取仍知所求；L1和L4明显不同。
4. 检查所有续题使用同一编号与“续”，目录和批注仍指向真实位置。知识地图删去后，有用对照表与总结应迁入速查，不能一并丢失。
5. 人类编辑未参与时，human_content/human_visual保持not_run；另记录agent_reading_review、agent_visual_review的实际页码与结果，不冒签。
6. 公开包只含language-calibration。private-language-reference中的README、索引、原文摘录全部排除；检查git check-ignore与打包文件列表，而不只口头声明私人使用。
