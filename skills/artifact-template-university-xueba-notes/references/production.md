# 制作与检查

## 活跃参考

以用户当前要求、实际查看的参考页和当前文字规范为准。2026年10月3日新增五科抽查，含生物与数学人教B版，具体范围见 `reference-observations.md`。漫画生成须查看实际可用的源图并作为图像参考传入工具；公开仓库没有私人裁片时，从用户提供的PDF取得相关参考，不把索引存在当作图像已经读取。

可复用PDF母版为 `Resources/templates/print-master.pdf` 与 `digital-master.pdf`，字段及网格见同目录 `template-manifest.json`。正常生成使用 `scripts/fill_template.py` 和独立内容JSON，遵循 `template-workflow.md`。

`Resources/examples/print-reference.pdf`、`digital-reference.pdf`、`foldout.pdf`为旧版排版实例，可参考现有几何与字段用法。其统计学第一页的概念堆积、例子距离与侧栏顺序须按新版规范重审；目录的视觉形式也尚未按新要求重建。旧 `verification.json` 记录原版本的检查，不代表新版教学验收通过。新版统计学样本完成内容改写、实际渲染与复核后再替换旧样本；提示词修改不能被记录为PDF已经重做。

## 制作顺序

1. 阅读来源，建立完整覆盖关系、先修顺序、核心概念ID和独立知识目录。
2. 确定版本与范围，检查原书普通页、典例页和侧栏漫画，记录标题和密度观察。
3. 读取既有模板与清单，选择合适页型；仅在缺少必要页型时扩充母版一次。
4. 编写大学层次的完整分目，按 `content-and-language.md` 完成定义、解释、例子、逐项对应与必要边界；先修先讲，条件随公式出现。先审教学链，再分别删去作者辩护和无信息语句。典例解答紧随题目，内容按需要增加页数。
5. 逐段阅读稿件，按当前论点选择荧光范围并记录理由；以原书裁片为输入生成分布于全章的原创侧栏漫画，原生绘制精确工作图，控制图表占位。
6. 将审定正文写入当前填充器实际读取的 `pages[].blocks`，逐项核对概念到正文的教学记录；不能只填写 `concepts`。登记目录、侧栏锚点、局部高亮与视觉关系。最后整理分章专有词汇表。先核查当前脚本能力，再选择受支持的页型；待实现字段遵循 `template-workflow.md`，不能直接假定可渲染。
7. 检查封面、分级目录、正文概念锚点、书末词汇表、学科速查、打印装订顺序和页码；封面不加入宣传口号。
8. 渲染全部页面并检查，修复受影响的内容、模板或填充规则后再渲染。
9. 保存实际完成的文件并说明范围。提示词或计划不能替代最终嵌入的插图。

字体可用 `scripts/prepare_fonts.py` 准备，保留许可并核对中文、英文、数学和手写字形。中文正文恢复第一版 LXGW WenKai Regular（霞鹜文楷），即 `WenKai.ttf` 的 `Body` 与 `Hand` 注册字体；不可静默替换为宋体，不可因字体恢复导致基线与横线分离。

## 检查项目

| 方面 | 必查内容 |
| --- | --- |
| 知识 | 逐个定位核心概念首次教学的定义、解释、例子、对应与边界；主栏独立可懂；公式解释符号、步骤理由与结果含义，先修顺序正确 |
| 目录 | 来自独立知识outline，册章单元节与正式教学栏目分级；分页标题、续页标题和页面装饰语不进入目录；页码与链接正确 |
| 书末词汇表 | 位于最后一个正式内容区；按章分组；每项只有英文术语与简明中文释义；不混入普通动词、连接语、句子碎片、题目措辞或答题用语 |
| 荧光 | 每处有段落锚点、精确范围与基于语境的编辑理由；高亮表达完整重点，条件与否定词不丢失；同词普通用例不随之高亮，跨行范围正确；无全局关键词扫描 |
| 密度 | 同类原书页面并排比较；以完整教学单元评估，不用术语数或字数代替；复查连续抽象段落、例子过晚、第一页多项首次定义及无教学作用的留白 |
| 图表 | 教学作用准确；工作图通常2–4正文行高；复杂树图或流程图按需要约4–5行；表格紧凑 |
| 漫画 | 实际裁片已查看并传入生图；细灰黑线、平涂色和角色五官与源图相符；原尺寸可读；覆盖章节前中后部，单独检查连续三页以上空缺，不能只集中在相邻两页 |
| 语言 | 知识名词或短栏目标题；无把句、从…到…标题、逗号、冒号、问号；正文避免把句及空泛名词化；不默认生成统一自测、独立答案或答案词汇 |
| 直接讲解 | 检查全部实际渲染文字；正文、标题、侧栏、图注、表格、漫画对白与答案无免责、辩护、自我解释、多余对冲或夸大误解警告；定理前提、变量范围、分母正值、模型假设、统计不确定性及题目要求的比较和理由完整且直接陈述；按语义判断，不用词语黑名单误删技术条件 |
| 信息量 | 删除空泛重要性、循环释义、同义重复和无作用过渡；保留提供计数范围、步骤理由及衔接作用的短句；以正文实际信息判断，不按禁词或句长打分 |
| 侧栏顺序 | 每项对应具体主栏块，在相关概念与符号讲清后阅读；默认无关键词列表；漫画对白解释关系；隐藏侧栏后基础教学完整 |
| 纸面与网格 | 两版均纯白；横线正常阅读可见；文字基线与模板横线固定对应 |
| 物理页底趣味条 | 页面最底部独立浅绿（#F3F7E0）横条，一至两行深色（#252823）文字；内容为短笑话、冷知识、学科知识或有出处的名言名句；不在页顶，也不属于正文结尾知识栏目 |
| 出版与批注 | 无裁切重叠；批注空间、装订边、页码、目录、书签、交叉引用正确 |

工作图不依固定大尺寸铺满页面。图前后采用紧凑行槽，微图可并排；表格内边距小，行高按所含文本占一行或多行网格，不设巨大固定高度。可读性或复杂推导确有需要时允许更大图，并记录知识理由。

物理页底趣味条从[结构化语料](fun-content.md)抽取短笑话、冷知识、学科知识或有出处的名言名句。优先一行，连同署名最多两行；根据实际字体和栏宽测量。每个有效页面使用不同条目，跨章节共用已用记录，输出定位记录保留所选ID和出处。内容避开性别歧视、政治冒犯或政治敏感、种族主义。趣味条属于模板固定页家具，不写入正文blocks或章末知识分区；正文先结束于条带上方，页码与条中文字互不遮挡。封面、故意空白页和独立折页不强制趣味条。

打印版核对奇右偶左外栏、内侧20 mm完全空白、正文第1页位于物理右页。电子版核对固定双侧批注和标准PDF批注可用。封面、正文、速查及空白批注区都保持纯白底。

全页检查密度与构图，实际阅读尺寸检查蓝线与文字关系，局部放大检查公式、典例解答、侧栏、书末词汇表及折页。文本抽取、字段声明和文件存在均不能替代视觉检查。计划校验器只辅助核对概念、目录、页面、视觉与词汇表的引用关系。

## 检查记录与修复判断

制作记录分别使用下列项目，注明输入版本、实际页或正文块、证据与结果。结果区分 `passed`、`needs_revision`、`not_run`；确实不适用时写 `not_applicable` 并给理由。提示词审查与成品审查是不同范围。

| 项目 | 通过依据 |
| --- | --- |
| structural_validation | ID、引用、先修顺序、页面承载及当前结构格式正确 |
| teaching_validation | 在实际主栏逐项找到教学链；读者能说明对象、符号、范围、对应关系、步骤及结果意义 |
| language_validation | 已逐段处理防御性表达、空话、循环释义与不必要重复，并保留真实条件与不确定性 |
| contents_reference_validation | 目录与实看的相应原书页并排核查：节点类型样式、栏式、页码、续页及插图关系 |
| visual_render_validation | 全页与局部放大阅读，检查字号、基线、裁切、重叠、密度及侧栏位置 |
| navigation_validation | 当前最终分页的目录链接、书签和页码一致 |
| glossary_validation | 分章顺序、专业性、字段限制及最后正式内容区正确 |
| asset_validation | 实际嵌入、标注准确、来源可追溯，输出范围符合请求 |

发现缺失定义、例子、对应说明、公式条件或未教先用时，先修正文再排版；修复语言时保留事实和必要推理。多项首次定义同页、长证明或连续抽象段落属于需要阅读判断的信号，不能单凭计数判失败。裁切、失效锚点或错误计算则直接修复。

每项教学检查记录概念ID、正文位置、五项内容的实际证据，以及修复后的复查结论。目录比较另记原书文件与PDF物理页、成品页、布局差异及修复理由。自动检索负责找候选，人工语义阅读负责判定；脚本未实现的语义检查不得写成自动通过。
