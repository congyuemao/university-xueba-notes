# 语言、例题、分段与语料库修订记录

日期：2026-10-04。依据本轮方案修改既有 Skill、内容 schema、渲染器与运筹学三章校准。字体、Hand 层和 version 7 母版沿用上一轮；母版、字体准备脚本和字体选择规范已逐文件与本轮起始提交核对一致。源数据、方案与最终 PDF 校验值见[复核数据](../Resources/examples/calibration-review.json)，参考页见[实查记录](reference-observations.md)。

## 方案落实

| 要求 | 落地与验证 |
| --- | --- |
| 正文不再按电报体压缩 | L1 首次教学用完整句、自然衔接及必要解释；把“每句新增事实”改为“每句承担教学作用”，只删机械重复 |
| 四层语言分工 | L1 首次教学、L2 概念复现、L3 例题、L4 侧栏/手写/速查；公开语料给出同一知识的不同密度 |
| 按语义分段 | 显式空行形成独立段落与网格间距；并列 LP 假设独立成项；高亮可跨语义段保留 |
| 公式与原因分开 | `formula_step` 先排解释再排公式；单纯形换元和 DP 递推已实际使用 |
| 题干自足 | 4 道完整例题各自交代对象、数据、范围、约束、所求；预算与利润标明万元，LP 应用标明批、吨、元 |
| 例题分区与步骤 | `worked_example` 渲染题目、分析、编号步骤、结果、方法；题目与分析、结果与方法分别保持邻接 |
| 续题可识别 | 自动分页保留原题号并标“续”；显式续题须引用已出现的同题，不能自引用 |
| 删除低密度地图 | 默认关闭独立地图；本样稿移除 2 页地图，应用/阶段/状态/决策表及方法总结迁入速查页 |
| 私人语料 | 两本数学书 8 页、40 条短摘录、14 个功能标签，逐条记录物理页、书内页、观察；不进入 Git 或公开 ZIP |
| 公开语料 | 5 份原创规则、自编例子与正反例；不以参考语料替代课程知识来源 |
| 自动语言提示 | 实测纯文字段落超过 4 行提示、6 行起人工复查；隐式前文依赖与多动作段落列为候选问题 |
| 保留既有视觉体系 | 不重做字体、Hand 和母版；必要渲染修改集中在语义段落、公式、例题分区及其分页 |

## 阅读与视觉复核

本轮由 Codex 实际读图和阅读，自动检查与代理复核分别记录；未取得外部人工编辑或真实学习者签审，`human_content` / `human_visual` 仍为 `not_run`。

连续阅读电子版物理页 3–5：先从生产情境说明决策变量与可行解，再读可行域与目标比较，最后将业务条件翻译成约束。定义、解释与例子有语义间隔，速查式短句主要留在图注、侧栏与方法总结。全文其余页面按知识衔接、题意、步骤、单位与结论阅读检查；这属于代理阅读判断，不作为真实读者疲劳度实验。

4 道完整题均能从本题题干恢复条件。LP 订单例得到 x = y = 2、利润 1000 元；单纯形完整例得到 z = 10 − s₁ − s₂，最优 x = y = 2；两阶段例得到 x = 0、y = 2、无量纲目标值 4；预算 3 万元全部分配，A 得 2 万元、B 得 1 万元，总收益 10 万元。DP 件数表的价值单位为元，F₂(7) = 10，回溯为甲 2 件、乙 1 件。数值正确性另有测试独立核算。

打印 23 页、电子 21 页均渲染并检查接触表；放大核对连续普通页、完整题、续页、DP 首次教学与表格、折页。最终 DP 递推页调整后另行渲染复查。关键公式单独成行，步骤按任务分隔，题号与续题标识稳定，手写锚点随分页迁移。没有靠缩小正文字体压回旧页数。

两版各有同一条节奏提示：`sx-example-cont-2: review three repeated page structures`。经阅读和视觉复核接受：它对应同一道典例 02 的三页完整迭代，续题标识明确，各步可定位。未降低检测阈值来隐藏提示。最终自动语言候选列表为空，但这不等同于自动证明语言质量。

## 验证结果

46 项测试通过、0 跳过，覆盖既有结构与数学检查，以及结构化例题、必要字段、续题引用、默认地图条件、长段与依赖词提示、公式独立基线、语义段间距、高亮和真实 PDF 分页。官方 Skill 校验与 v2 计划校验通过，旧统计学 v1 内容实际再生成 6 页成功。

`scripts/audit_calibration.py` 检查三份 PDF 的尺寸、文字页边界、缺字、打印装订边、侧栏重叠、纵向容量、趣味条去重、嵌入字体与目录链接。检查结果及已复核提示完整写入复核 JSON，不把人工字段改成通过。

本轮仅校准精选教学单元，未重做 Taha 全书；未进行独立模型生成评测、实体打印或真实学习者实验。过高的不可拆教学单元仍须由编辑选择断点。
