# 按学科选择视觉教学

## 四种尺度

| 尺度 | 教学任务 | 位置 |
| --- | --- | --- |
| 微型解释图 | 一个区别、方向或对应关系 | 副栏、公式旁、易错说明旁 |
| 正文工作图 | 参与推理、计算或操作 | 正文解释与完整解答 |
| 概念漫画 | 建立记忆锚点、呈现问题或误区 | 教学副栏或局部解释区 |
| 大型知识场景 | 展示一册或一章的联系 | 册级开场、章节总览 |

各尺度按知识需要使用。漫画不替代工作图，工作图不代替定义与条件。大型场景包含准确标签和关系。

## 学科语言

| 学科 | 重点关系 | 适合图形 |
| --- | --- | --- |
| 数学 | 包含、映射、几何与逻辑 | Venn 图、数轴、坐标图、函数变换、几何图、结构图 |
| 物理 | 方向、空间、变化与过程 | 自由体图、轨迹、x–t 与 v–t 图、器材、电路、光路、场线 |
| 化学 | 微观结构、实验现象与转化 | 分子图、电子层、装置、颜色前后、沉淀、反应路径、转化网络 |
| 历史 | 时间、空间、人物与证据 | 年代轴、地图、关系图、文物或建筑照片、史料对照 |
| 统计 | 分布、变异、抽样与推断 | 直方图、箱线图、密度、频数格、概率树、抽样模拟、区间、散点与残差 |
| 计算机 | 状态、数据、执行与结构 | 数据结构图、执行轨迹、递归树、流程、网络拓扑、状态转换、增长曲线 |
| 其他 | 课程实际关系 | 先确定教学问题，再选择精确工作图或原创场景 |

不能用同一套小人和随机图标替代各科工作图。历史材料附来源与时间，科学图保留单位和比例，概念图注明理想化条件。箭头分别说明时间、方向、流程、映射或因果，避免一种无标签箭头表达多种含义。

物理页优先让运动图像、自由体图、光路、电路或实验器材与定义和条件相邻；“核心素养”只在确有方法或能力归纳时成为正式目录节点。化学页在适用处并列宏观现象、微观粒子和符号方程，解题模板必须关联反应条件或守恒关系。历史页先建立时间与空间坐标，再用史料、人物和制度关系支撑判断；地图、时间线和因果箭头都要标明所表达的关系。

## 统计图的准确性

条件概率图突出条件发生后限定的样本空间。贝叶斯示例优先用人数、频数格或概率树，明确基准比例、检验性能和更新概率。侦探漫画表示依据证据更新判断；一般的 P(A|B) 不自动说明 A 导致 B。

总体与样本、数据分布与统计量的抽样分布使用不同图层，明确横轴含义。置信区间图可画重复抽样的区间，标注真参数固定及长期覆盖率。相关图保留数据与轴，不画成因果流程。独立事件与互斥事件的图保留概率条件。

## 覆盖记录

每个核心概念记录概念 ID、关系类型、图形、教学用途、来源或数据、精确标签、页型、绘图方式、嵌入位置与核对状态。

分页后检查连续纯文字知识页。存在流程、比较、变化、空间或对应关系时，检查缺少工作图的原因。确实适合文字的部分可以保留并记录理由。审查全章覆盖，不采用机械图片数量。

## 尺寸

根据原书实际页面测量图表相对主栏宽高。普通工作图通常2–4正文行高，复杂树图和流程图约4–5行，必要细节可合理扩展；微图适合并排。图前后不保留过量空白。表格小内边距，行高依实际内容占用一个或多个基线行，禁止巨大固定行高。文字及标签在最终大小下必须可读，不能通过放大简单图形填满版面。

## 运筹学的工作图与章节重组

| 主题 | 优先载体和节奏 |
| --- | --- |
| 第一章 | 先用完整工坊/面包店图解教变量、参数、目标、约束、可行解；下一页最优解及遗漏原料的反例；再用表/小图比较确定、随机、排队、仿真。总览提名不算taught |
| LP | 比例性/可加性/可分性三格比较；放大可行域；语句到约束表；多期时间轴；Solver放应用或侧栏 |
| 单纯形 | 基列选择图、入基出基红箭头、枢轴高亮表、两阶段完整例题；退化/多重最优/无界/不可行四格辨析 |
| 运输 | 成本与运量表、位势、闭回路正负标记、调整前后；数据与推导就地对应 |
| 网络 | MST边权图、最短路标号、最大流残量/增广网络、CPM活动图前推倒推、PERT三点估计 |
| 启发式 | 学习版至少分别处理局部搜索，禁忌/退火，遗传算法，约束规划/比较四个教学页；各有轨迹/状态/温度/候选变化图，不两页塞完 |
| TSP | 子回路图；2-opt的断两边→反接→新路线图；最近邻与2-opt应用页；精确与启发式对照 |
| DP | 不同历史汇合到充分状态图、递推表、保存决策与回溯；人员/设备决策图；章末方法树 |
| 库存 | 锯齿与补货时间轴、开机与持有费表；数量和费用单位严格区分 |
| 随机系统 | 马尔可夫状态图、排队生灭图、仿真事件时间线，公式跟随状态解释 |
| 非线性 | KKT条件与几何，搜索方向与迭代轨迹；高级数值边界分C级 |

LP、单纯形和DP是本轮校准切片，其余主题作为将来完整课程稿的组织要求；不把未重做章节声明为已完成。网络、库存和排队的图必须由具体数据绘制，不用通用流程框替代。
