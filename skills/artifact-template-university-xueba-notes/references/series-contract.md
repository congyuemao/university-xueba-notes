# 系列一致性规范

## 目标与固定项

新书应像同一出版社发行的学科系列，复刻格式、视觉风格与知识讲解安排。课程内容重新编写，角色和学科图重新制作。相似性不能只由绿色标题或一张漫画承担。

先建立全书共用的样式表，之后各章使用同一套规则，不逐页重新决定字体、色板、标题形状和漫画风格。下列项目固定：

| 固定项 | 规范 |
| --- | --- |
| 正文纸面 | 两版均纯白无整页底色，蓝色横线清晰可见；实际文字基线与横线共用模板网格 |
| 正文字体 | 恢复第一版的 LXGW WenKai Regular（霞鹜文楷），`Body` 对应 `WenKai.ttf`，`Hand` 独立使用龙藏 `LongCang.ttf`；当前母版正文11.6 pt，按模板清单保持可读密度与基线网格；原书宋体观察不能覆盖该字体选择 |
| 数学与英文 | 字形完整的配套字体，公式单独排版，英语自然换行 |
| 手写层 | 清晰字体配红橙色、适度基线变化、短批注、箭头和圈词，与文楷正文保持可见层次 |
| 标题层级 | 小绿册级标签；开章黑色主标题；绿色或黄绿笔刷式小节条；深蓝知识编号 |
| 目录 | 独立知识树与专用白底无横线母版；册级横条、强章单元标题、节课明细和所属专题按kind区分，页码右对齐；分页标题不入目录 |
| 强调 | 逐段按具体语境选择关键命题、条件、因果与结论，黄色荧光铺在对应正常字重文字下；禁止全局关键词搜索匹配高亮 |
| 栏目 | 定义、性质、典例、解析、方法、图解与易错说明，名称稳定 |
| 副栏联系 | 同编号或细箭头对应具体主栏锚点，避免完全独立的无关提示 |
| 漫画 | 以实际查看且可用的原书裁片为图像参考；细灰黑线、平涂印刷色、眼白与瞳孔眉毛、豆形或袋形概念角色、紧凑教学构图；小型侧栏漫画按知识任务分布于全章 |
| 首次概念教学 | introduced允许先提名；正式taught完成五项章节检查，可分配到图表例题与侧栏，核心定义和主推理在主栏；A条件紧贴，B/C分级 |
| 分章专有词汇表 | 位于全书最后，按章分组；每项只有标准英文术语和简明中文释义，不承担正文教学 |
| 表格 | 小内边距，行高按文字占用一个或多个正文网格行，浅色表头与少量强调，无巨大固定高度 |
| 工作图 | 通常2–4正文行高，复杂树图约4–5行，微图可并排；尺寸以原书相对大小及清晰度校准 |
| 物理页底趣味条 | 页面最底部独立浅绿 #F3F7E0 横条，y=275 mm、高10 mm，一至两行 #252823 深色文字；固定页家具，不放页顶、不作为正文结尾知识栏目，页码不遮挡文字 |
| 封面 | 同样的主标题形、科目标牌、人物层与学科名层，按学科换色和小图 |
| 阅读节奏 | 以完整教学单元计密度；可有数个相关短分目，也可有一个长推导及例子；具体对象尽早进入，保持图表与解释相邻 |
| 标题措辞 | 真实知识名词与固定栏目短语，无把字句、从…到…、逗号、冒号或问号 |
| 模板复用 | 固定PDF母版与内容JSON分开保存；正常成书填充既有母版，不重复编写页面框架 |

颜色使用 `visual-system.md` 的同册色板。纸面和字体根据参考与实际字体一次性校准，后续稳定使用。字号可以因A4适配调整，不能为了塞入内容持续缩小。正文按已选定的霞鹜文楷加载并嵌入；缺少字体时先恢复随附或获许可的字体资源，不静默替换成宋体或其他字体。手写批注使用独立龙藏字体，并通过色彩与圈画分层；比较样本见font-selection.md。

绿色大块开章条和巨大孤立数字不是唯一标题形式。使用原书可见的黑色章标题、笔刷式小节条与蓝色知识编号层级。开章标题仅在章节开始出现，续页恢复内容空间。小节条可以在真正开始新小节时出现。

## 按学科变化的部分

允许变化：封面主题色、学科角色、工作图类型、知识总览场景、速查结构、题型与课程术语。固定人物画法、线条、气泡、栏目层级、标记色与知识说明方式。

数学可通过定义、性质、关系图和典例展开；物理可通过模型、受力图、运动图像、装置和条件展开；化学可通过分类、宏观现象、微观结构、符号表达与反应条件展开；生物可通过结构、过程、功能与实验观察展开；历史可通过时间线、地图、制度结构、史料和因果链展开；统计可通过数据情境、定义、图形、条件与计算展开。每节顺序随知识需要变化，仍保留短解释与完整推导的系列表达习惯。

## 目录的视觉语法

参考本轮五本书实际目录，采用同系列下两种变体：双栏密集型适合短标题较多的知识树，主目录加插图侧栏型适合长标题与主题分组。统计学样本优先双栏，实际条目较少时按内容分组，不虚构章节填满页面。

| 节点kind | 目标外观 |
| --- | --- |
| part | 浅黄或学科色册级、模块横条 |
| chapter、unit | 红褐色粗体标题与同色页码 |
| section、lesson | 黑色较小文字、稳定缩进与点线 |
| feature | 深色加粗短栏目，归属于相关章、节或单元 |
| appendix | 独立浅色横条或附录标题 |

`level`保存父子深度，`kind`决定外观；编号与名称在编辑计划中分开记录。目录第一页可用较大标题，续页简化页眉。页码固定在同栏右边，长标题悬挂缩进；点线采用绘制引导线而非反复输入字符。父标题下至少保留一个子项，专题与所属条目尽量同栏。

目录主框独立于正文蓝横线系统，保留白底、轻边框、栏间间隔以及物理页底趣味条。目录插图绑定邻近知识组，表现实际对象或关系；只负责导航与识别，不抢先教授新概念。版本7母版与v2填充器已实现kind样式、无横线目录、测量栏平衡、父首子控制和相关插图；仍须按template-workflow.md实际检查尾页、导航与构图。

## 成稿前校准

先制作同一课程的一个开章知识页、一个续页、一个工作图或完整例题页。以所提供的原书参考并排检查纸面、字体、标题、主副栏、强调方式、手写层和漫画，再继续全书。小样用于内部校准，用户已要求整书时不等待额外确认。

打印和电子版各检查其最密的一页。两种版本的书写位置不同，视觉身份与知识讲解方式相同。

## 系列漂移判定

出现以下现象时返回校准：全部知识再次成为长段说明；核心概念首次正式教学仍没有定义、通俗解释或例子；目录只是页面标题列表；每页同样四段模板；手写层变成统一印刷卡片；工作图缺失却堆叠装饰漫画；全局关键词机械高亮；书末词汇表混入普通动词、句子碎片或题目表达；工作图被随机图标取代；章节字体或漫画画法变化；正文像应用界面；速查表被缩到无法阅读；幼儿Q版或粉雾彩铅替代原书画法；一个浅显知识点占满一页；标题成为带标点的教学口号；模板横线与正文基线脱离。

校准检查不能只凭感觉。逐项记录通过或需修复及对应页。额外检查两版白底、横线对应实际基线、主栏知识密度和大学教学深度；漫画比较必须并排查看实际原书裁片。正文完整性、页面相似度、漫画风格、视觉覆盖与书写空间分别检查。保留逻辑可读性与实际批注用途，不通过扫描损伤或商业标记制造相似。

## 六层协作与章节留白

印刷知识、图表、例题、荧光、手写二次加工、侧栏教学协作，是复刻的核心。Body继续文楷，Hand独立；手写用于补式、方向、圈词、一步推导、错误写法和简短关系，不只是红字结论。主栏主干完整，侧栏可承担真正补充教学。

默认按章节面积加权保留至少35%侧栏书写空间，可按用户需要调整；不再逐页要求一半空白。独立知识地图默认关闭，仅用户明确要求且信息量足够、能总结已学内容并保留教学空间时启用；启用时用彩色贝塞尔有机分枝，公式和图挂在枝条上。普通、图解、过程、完整例题和综合页按任务变化；每个大章评估综合应用，3–4页同构图复查。
