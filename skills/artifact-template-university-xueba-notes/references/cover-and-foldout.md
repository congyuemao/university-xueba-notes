# 封面与附带知识速查

## 系列封面

完整书籍默认有正面封面。单章、局部修订或样本任务按范围决定。封面保持同系列的构图关系，使用原创学科元素和大学课程标题，不复制出版社商标、ISBN或营销内容。

固定构图关系：电子版使用学科主色铺底；打印版使用纯白底和局部学科色以节省墨水；中央突出黑色不规则主标题块；白色大字“学霸笔记”；白色科目或范围标牌；下方原创学科人物或拟人概念；底部明确学科名称；小型图形与知识线作为点缀。品牌位置可以省略或使用用户指定名称。红色小标仅在有真实版本信息时添加，不自动复制 PLUS。

同系列的封面层级、标题字形、人物画法、标签比例与留白关系固定。各学科变化主色、人物、科目范围和微型工作图。统计学可使用正态曲线、散点、概率树与数据角色。

只生成插画层；主标题、科目标牌和版本信息单独排版。检查看缩略图仍可识别学科和系列，放大后小图与文字清晰。书脊或后封仅在用户要求或实际装订规格需要时设计。

## 知识速查的内容结构

知识速查采用符合学科的构图。它承担快速定位和关系恢复，正文仍保留完整知识。

| 学科 | 合适形式 |
| --- | --- |
| 化学 | 方程式、反应条件、物质转化网络与现象对照 |
| 历史 | 时间与主题矩阵、地图及人物关系 |
| 数学 | 公式、条件、性质与小图形的多栏手册 |
| 生物 | 多色关系图、系统结构和关键流程 |
| 统计 | 公式、选择流程、分布关系、图形与条件 |

统计学可按描述统计、概率规则、常见分布、抽样分布、置信区间、假设检验和回归分区。范围受课程控制，不添加未学主题。公式配适用条件，检验流程配前提。全表符号与正文相同。

## 超宽页面与打印

保留一张可放大查看的横向超宽页，尺寸由文字量与实际用途决定。A3 横向或更宽折页都是候选，不能把全部内容缩成 A4 纵向。正文、标注和公式在目标打印尺寸下优先至少 9 pt，必要时扩大纸面或分区。

电子版提供完整超宽页，文字可搜索，图形放大清晰。打印版提供折页大纸版本；需要常规打印时额外提供完整的 A4 分块版。分块保持原比例，标明块号和组装关系，可留约 5 mm 拼接重叠区。

一张超宽页和 A4 分块来自同一内容与坐标，不能删减难放的部分。检查覆盖整个纸面、公式不跨在不可读边缘、最终字号和全部分块。折页单独文件可避免干扰双面正文的奇偶页关系。

## 成书前部

封面、必要空白背面、目录与总览的顺序保持一致。版权页、广告和商业宣传省略。打印版按物理页序核对正文页1位于右手页。单独速查折页不参与正文逻辑页码。内容页保留短页脚，封面与空白背面没有趣味页脚。
