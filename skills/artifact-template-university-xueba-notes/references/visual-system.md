# 视觉体系

## 参考的优先关系

当前用户要求优先，其次为本 skill 的更新规范，再次为用户提供的教辅参考，最后为保留的旧样稿。旧 DOCX、14 页样稿和渐近分析漫画属于历史材料，只能辅助核对旧版几何关系。

用户提供的数学、物理、化学、历史正文，以及分离式封面，可以作为具体视觉参考。引用某幅漫画的角色、台词或页码前，实际查看相应页面。未查看部分仅作为设计建议。选择知识页、图解页、综合题页、总览与封面，记录来源、PDF 物理页号、页面显示页码和裁切区域。放大查看副栏线条、气泡、配色和文字关系。

扫描歪斜、模糊、底噪、压缩痕迹及水印属于来源损伤，新稿不复制这些损伤。整本扫描与参考裁片不自动加入公开分发包。制作原创角色和学科场景，保留参考的教学构图规律。

## 五层页面

| 层次 | 做法 | 检查 |
| --- | --- | --- |
| 纸面 | 打印版纯白且不绘制整页底色；电子版暖白，约 #FFFEF8 | 打印节省墨水，电子保持纸感 |
| 横线或细格 | 极浅蓝，约 #E3EDF4，线宽 0.25–0.4 pt | 不穿过装订空隙，不干扰公式 |
| 印刷知识 | 黑色正文、稳定编号、表格、公式与工作图 | 主栏逻辑完整、文字可搜索 |
| 荧光与手写 | 黄色局部标记、红橙解释、细箭头和圈线 | 正文清晰，无互相遮挡 |
| 插图 | 微图、漫画、学科工作图、总览场景 | 对应明确知识用途 |

避免大面积界面卡片、阴影、玻璃效果、现代应用式按钮和重复圆角模块。综合题可以有薄蓝色框，表格和图解可以有功能性边界。

## 颜色语义

| 用途 | 建议色 | 使用原则 |
| --- | --- | --- |
| 正文 | #242424 | 承担大多数知识 |
| 编号与小标题 | #164878 深蓝 | 便于定位层级 |
| 章节与小节条 | #259C62 绿色或学科色 | 稳定标识，不重复整页开场 |
| 荧光笔 | #FFE875 黄色 | 局部关键词或关键条件 |
| 关键公式或概念 | #C54335 红色 | 有选择地强调 |
| 手写批注 | #D05A36 红橙 | 原因、辨析、方法、箭头说明 |
| 副栏标题 | #168BA6 青蓝 | 区分主、副信息 |
| 背景与分类 | 少量橙、浅绿 | 分类确有帮助时使用 |

色值是实现起点，查看参考后可以统一调整，优先可读性与同册一致性。多色不要求每页同时出现所有颜色。

## 荧光与手写

荧光标记铺在文字下层，保留正常字重。允许轻微不规则边缘和起止变化，不越过相邻文字。标记关键词、关键假设和易漏条件，避免整段铺满黄色。

手写字与正式印刷体有可见区别。选择清晰手写字体，短批注可以轻微倾斜、错开基线，变化不得损害阅读。正式证明、长定义和复杂英文解释保留印刷正文。

批注围绕具体锚点，例如条件、方向或易混公式。短弧线、细箭头、圈词和简短说明构成解释单位。红色印刷“注意”卡片不足以表现手写层。无需每处都添加提示词。

箭头起点和终点明确，不穿越长段正文或遮盖符号。分页后复查指向。

## 主副栏与书写空间

参考书约 6:4 的关系体现解释副栏的重要性，是视觉参考比例，随学科和页型变化。普通页保留打印、电子版既定坐标与书写区域。不能用固定 60% 主栏宽度牺牲用户批注空间。

大型图解、综合题或教学跨栏页可采用约 60:40 的解释分配，在下方或邻页补足批注空间。数字版仍有两侧批注区域。打印版仍有外侧批注和完全空白的内侧装订边。宽表页按版式规范处理。

每章约半数或更多批注区域可供书写。教学图和漫画靠近相关主栏内容；未使用空间保留。窄栏容纳不下的漫画转入局部正文解释区，不能一味缩小字图。
