# 视觉体系

## 参考的优先关系

当前用户要求优先，其次为本 skill 的更新规范，再次为用户提供的教辅参考。使用能满足当前页型要求的母版；`Resources/examples/`只作旧版几何参考，不能作为新版教学与目录形式已通过的证据。知识组织和漫画画法对照实际查看的原书页。

用户本轮提供的数学人教B版、物理、化学、生物与历史正文作为参考；旧版其他数学文件及封面记录单独保留，不混用页码。引用某幅漫画的角色、台词或页码前，实际查看相应页面。未查看部分仅作为设计建议。选择知识页、图解页、典例页、总览与目录，记录来源、PDF物理页号、书内页码及查看方式。

扫描歪斜、模糊、底噪、压缩痕迹及水印属于来源损伤，新稿不复制这些损伤。按用户要求保存实际漫画裁片至 `Resources/reference-comics/`，并保留来源索引。整本扫描与私人参考裁片不自动加入公开分发包。制作原创角色和学科场景，保留参考的教学构图规律。

## 页面分层

| 层次 | 做法 | 检查 |
| --- | --- | --- |
| 纸面 | 打印与电子版均纯白，不绘制整页底色 | 封面、正文、折页及空白批注区无暖白、奶油或黄色底 |
| 横线或细格 | 正文使用细蓝线，与文字基线共用网格；目录主框使用专用无横线布局 | 普通阅读尺寸可见；正文基线稳定；不穿过装订空隙 |
| 印刷知识 | 第一版霞鹜文楷黑色正文、稳定编号、表格、公式与工作图 | 主栏逻辑完整、文字可搜索；保持可读字号与当前网格 |
| 荧光与手写 | 黄色局部标记、红橙解释、细箭头和圈线 | 正文清晰，无互相遮挡 |
| 插图 | 微图、漫画、学科工作图、总览场景 | 对应明确知识用途 |

避免大面积界面卡片、阴影、玻璃效果、现代应用式按钮和重复圆角模块。综合题可以有薄蓝色框，表格和图解可以有功能性边界。

## 颜色语义

| 用途 | 建议色 | 使用原则 |
| --- | --- | --- |
| 正文 | #242424 | 承担大多数知识 |
| 编号与小标题 | #164878 深蓝 | 便于定位层级 |
| 章节与小节条 | #259C62 绿色或学科色 | 稳定标识，不重复整页开场 |
| 荧光笔 | #FFE875 黄色 | 按具体语境选出的关键命题、条件、因果关系或结论 |
| 关键公式或概念 | #C54335 红色 | 有选择地强调 |
| 手写批注 | #D05A36 红橙 | 原因、辨析、方法、箭头说明 |
| 副栏标题 | #168BA6 青蓝 | 区分主、副信息 |
| 物理页底趣味条 | #F3F7E0 浅绿底、#252823 深色文字 | 独立固定页家具，y=275 mm、高10 mm，一至两行；不进入正文栏目 |
| 背景与分类 | 少量橙、浅绿 | 分类确有帮助时使用 |

除已明确指定的页底趣味条浅绿底与深色文字外，其他色值是实现起点，查看参考后可以统一调整，优先可读性与同册一致性。多色不要求每页同时出现所有颜色。

## 荧光与手写

**荧光重点必须按具体段落、具体语境逐处判断。** 先读完整解释，判断读者应记住或理解的定义、条件、转折、因果联系、比较或结论，再选取表达该重点的完整短语或分句。保留必要的否定词、条件和关系词，不能只涂一个名词而丢掉命题。同一个词在不同段落承担的作用不同，只有当前语境中需要强调的那一处才标记。

禁止建立全局关键词表后搜索匹配、全文高亮，禁止以出现频次或术语名单代替阅读判断。不能先执行机械关键词高亮再称其为“情景高亮”。稿件记录每处重点所在段落、精确范围与简短编辑理由，理由留在制作资料中。填充器仅绘制已选定的局部范围；换行后连续标出对应片段，正文改动后复核范围。

例如，解释“均值受极端值影响，中位数通常较稳定”时，可以强调“均值受极端值影响”和对应的比较结论；同页练习题中的普通“均值”无需随之变黄。历史段落讨论停运如何影响供给时，重点可落在“运输受阻使原料与食品供应减少”这一因果关系；其他段落的“运输”“工人”等相同名词不自动高亮。选择仍以最终段落的论证任务为准，示例不构成词语名单。

荧光标记铺在文字下层，保留正常字重。允许轻微不规则边缘和起止变化，不越过相邻文字。控制标记数量，避免整段铺满黄色。检查时连同上下文阅读每处高亮，确认它能提示本段核心关系；再检查同词的普通用例保持正常正文。

中文正文恢复第一版 LXGW WenKai Regular（霞鹜文楷），Body注册WenKai.ttf，正文11.6 pt；Hand独立注册龙藏LongCang.ttf，短批注通常12 pt；原书宋体只能作为来源观察，不覆盖本次明确选择。手写批注通过红橙色、圈词、箭头与适度基线变化形成可见区别，短批注可以轻微倾斜，变化不得损害阅读。正式证明、长定义和复杂英文解释保持稳定正文排版。

批注围绕具体锚点，例如条件、方向或易混公式。短弧线、细箭头、圈词和简短说明构成解释单位。红色印刷“注意”卡片不足以表现手写层。无需每处都添加提示词。

箭头起点和终点明确，不穿越长段正文或遮盖符号。分页后复查指向。

## 主副栏与书写空间

参考书约 6:4 的关系体现解释副栏的重要性，是视觉参考比例，随学科和页型变化。普通页保留打印、电子版既定坐标与书写区域。不能用固定 60% 主栏宽度牺牲用户批注空间。

大型图解、综合题或教学跨栏页可采用约 60:40 的解释分配，在下方或邻页补足批注空间。数字版仍有两侧批注区域。打印版仍有外侧批注和完全空白的内侧装订边。宽表页按版式规范处理。

书写空间按章节侧栏面积加权核算，默认至少35%并允许用户调整；每页比例不固定。教学图和漫画靠近相关主栏内容；未使用空间保留。窄栏容纳不下的漫画转入局部正文解释区，不能一味缩小字图。

## 基线与横线

横线是实际书写及排版基准。模板记录首条基线、行距、每行相对横线的固定偏移和可用行数。正文行距采用同一网格间距；正文起点、段落间距、标题、表格与公式的占位高度均按整行或模板明确允许的半行安排。正文基线与横线的相对位置应全页一致，不能先铺横线再独立排字。

明确区分正文行、标题槽、公式槽和图形槽。公式中心、图表内部坐标无须强行贴线，但它们的外框起止位置遵守模板行槽，冲突区域按模板留白或遮去横线。批注手写的局部圈词与箭头允许自然变化，正文印刷字不随意上下漂移。

蓝线起始色可采用约 #9ED5DE、0.4 pt，最终以原书截图并排与实际阅读尺寸为准。不能仅因屏幕放大可见就判定合格。数值属于校准起点，模板确定后统一使用。

## 密度校准

从本轮五科参考中选择与教学任务相近的普通知识页，并查看相应典例或工作图。记录完整教学单元、解释与图表比例、例子距离、知识连接及标题尺度。按可用主栏面积比较，不直接比较不同纸面尺寸的总字数。

普通页以已经讲完整的单元为密度依据。定义附近有解释与例子，例子逐项对应定义；图表须进入当前推理。深度证明可以占较大空间，短分目可以合页。不为填页压入未准备的概念，也不通过缩小字体、重复句、巨大空白或装饰漫画增加表面密度。

目录视觉单独检查册级横条、强章标题、节课明细、专题归属、页码与图文关系；不能只检查标题缩进。具体要求见 `series-contract.md` 与 `page-types.md`。这套目录目标需通过实际母版和渲染实现，纯文字提示词不等于视觉成品。

## 六个教学层与真实手写对象

页面教学层分别是印刷知识、图表、例题、荧光、手写加工、侧栏教学。纸面与横线是它们的载体。知识图表承担主解释，例题连接应用，荧光突出语境判断，手写表现读过之后的二次加工，侧栏承担补充路径。

handwritten_layer绑定块/单元格/局部文字范围，支持短句、曲箭头、圈词、下划线、波浪线、小括号、打叉和小图槽。轻微旋转只用于手写，不能扰动正文基线。文字与圈画分别测量；批注不覆盖核心公式。每页评估，不强制空泛口诀。

默认不生成独立地图；只有用户明确要求、信息量足够、总结已学内容且不挤占正文例题时启用。启用后，volume_map与chapter_map采用原生曲线与SVG导出，多级彩枝、文字/公式/小图挂枝，允许不规则但受控的空间。矩形工作流程仍可用于算法本身，但不能作为默认知识地图。

目录测量节点高度并全局分栏，避免余下几项独占末页。尾页密度告警、两栏平衡和插图视觉锚点共同审查。工作图、表格、公式组优先于漫画装饰；大空白先通过教学单元重排解决。
