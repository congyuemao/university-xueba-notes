# 参考页面校准流程

使用用户提供的参考时，在有权访问的环境中实际查看页面。选择开章知识页、续页、精确工作图、概念漫画、综合题、总览、封面与知识速查，建立本次任务的视觉校准记录。

## 校准对象

| 对象 | 核对内容 |
| --- | --- |
| 纸面 | 底色、横线或细格、对比与清晰度 |
| 标题 | 册级标签、章标题、小节条、知识编号 |
| 内容单位 | 定义、性质、表格、图解、典例与完整解析 |
| 主副栏 | 宽度关系、对应编号、箭头锚点与书写空白 |
| 手写层 | 字体、颜色、圈词、短说明与方向 |
| 漫画 | 轮廓、头身、五官、浅彩、气泡、背景与教学用途 |
| 封面 | 主标题构图、科目标牌、人物与学科名层级 |
| 速查 | 页面比例、内容分区、公式条件与目标字号 |

临时记录来源位置便于复查。实际记录由当前用户资料决定。生成的系列规则可以复用；具体源文件、裁片和来源定位信息按用户授权范围管理。

## 使用观察

先制作开章知识页、续页和工作图或例题页，按系列一致性规范逐项并排检查。观察扫描损伤并将其排除在新稿之外。需要具体角色、台词或结构时先放大查看，未查看部分不写成已验证结论。

保持知识重新编写、插画原创与学科图准确。参考校准不能代替成品逐页渲染检查。
