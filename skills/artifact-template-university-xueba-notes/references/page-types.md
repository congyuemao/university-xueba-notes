# 页型与章节节奏

| 页型 | 主要任务 | 构图要点 |
| --- | --- | --- |
| 正面封面 | 学科识别与全书入口 | 纯白底、局部学科色、黑色标题形、科目标牌、原创人物或数据角色，无宣传口号 |
| 目录 | 通过页码导航 | 多栏可用，章节色标，少量漫画，不干扰条目 |
| 知识速查 | 快速检索 | 学科决定的超宽公式、关系、判断流程和图形组合 |
| 册级总览 | 展示知识全貌 | 大型场景或知识地图，分区标注关键联系 |
| 普通知识 | 完整而相关的知识分目 | 数个有逻辑联系的定义、条件、推导、表格、紧凑工作图与典例，密度对照原书 |
| 视觉解释 | 展示关系与变化 | 主工作图、局部放大、前后对照与必要解释 |
| 实验或过程 | 器材、操作与观察 | 连续装置图、流程箭头、现象变化、误差说明 |
| 完整例题 | 示范思考与计算 | 完整题目、命名步骤、过程图、解答与解释 |
| 核心素养提升 | 连接多个知识点 | 细蓝框、01/02/03典例、解析、方法、副栏思路 |
| 章末再读 | 恢复章节关系 | 思维图、比较表或关联图，短解释与答案导航 |

按课程内容选择页型，不要求所有学科都有实验页。完整册级任务应考虑总览、知识页、工作图、例题、综合题和速查。章节样本按范围选用。

普通页的标题、颜色和线条形成系列一致性；不同教学任务使用不同构图。小节编号服务内容层级。不要把整册写成标题、四段文字、公式、同一副栏的重复序列。

## 章节连续性

统计概率章可依次组织事件及其关系、条件概率与乘法公式、全概率与贝叶斯公式、典例精析、综合辨析和知识联系。以上是知识顺序，并非每个项目独占一页。一个普通页通常容纳数个完整的相关分目，小型Venn图、频数表和关系图可与推导及例题并排或相邻。实际密度按原书同类页面校准。

长章连续数页知识后，视内容插入实验、场景总览、完整例题、关系图或综合题。变化帮助理解，不通过无关插画制造翻页变化。不设固定每三页换模板的配额。

## 综合题页

延续教辅“核心素养提升”的功能，大学课程可用“综合理解与应用”等名称。适当标示难度，避免无依据的星级。

典例包含完整题目、分析入口、完整解答、方法归纳和必要条件。副栏可有常见错误、关键观察或替代路径。英语考试保留全部英文解答，示范例题可保留英文原题。章末自测、自查和闭书回忆另按中文提问、完整英文作答，不能被默认全英文练习规则覆盖。不能只给公式套用或省略证明步骤。

## 导航

章节标题、目录、正文编号、答案引用与 PDF 书签使用同一标识。最终分页后生成目录页码。跨栏或大图不切断问题与答案对应关系。两种版本可以页码不同，概念、题目与答案 ID 必须一致。

## 图表尺度

正文工作图通常约2–4正文行高，复杂树图或流程图约4–5行，确有精细标签或推理需要时再扩大。微图可横向并排，图前后留白按模板行槽安排，避免一张简单图独占半页。表格采用小内边距，行高由实际文本占用一个或多个网格行决定，不统一设置巨大行高。侧栏漫画沿用原书窄栏相对比例，保持主体与图表的空间关系。

所有页型来自可复用PDF母版。每个正文页在物理页面最底部保留独立浅绿（#F3F7E0）趣味横条，用一至两行深色（#252823）文字排版；该条属于固定页家具，不是正文末尾的知识栏目，不得移到页顶。页码与条中文字互不遮挡。标题使用真实知识名词与简短栏目名，遵循内容语言规范。
