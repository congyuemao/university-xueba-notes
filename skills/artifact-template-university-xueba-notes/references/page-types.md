# 页型与章节节奏

| 页型 | 主要任务 | 构图要点 |
| --- | --- | --- |
| 正面封面 | 学科识别与全书入口 | 学科主色、黑色标题形、白色科目标牌、原创人物或数据角色 |
| 目录 | 通过页码导航 | 多栏可用，章节色标，少量漫画，不干扰条目 |
| 知识速查 | 快速检索 | 学科决定的超宽公式、关系、判断流程和图形组合 |
| 册级总览 | 展示知识全貌 | 大型场景或知识地图，分区标注关键联系 |
| 普通知识 | 基础概念与条件 | 短解释、条目、表格、公式、微型图、相关副栏 |
| 视觉解释 | 展示关系与变化 | 主工作图、局部放大、前后对照与必要解释 |
| 实验或过程 | 器材、操作与观察 | 连续装置图、流程箭头、现象变化、误差说明 |
| 完整例题 | 示范思考与计算 | 完整题目、命名步骤、过程图、解答与解释 |
| 核心素养提升 | 连接多个知识点 | 细蓝框、01/02/03典例、解析、方法、副栏思路 |
| 章末再读 | 恢复章节关系 | 思维图、比较表或关联图，短解释与答案导航 |

按课程内容选择页型，不要求所有学科都有实验页。完整册级任务应考虑总览、知识页、工作图、例题、综合题和速查。章节样本按范围选用。

普通页的标题、颜色和线条形成系列一致性；不同教学任务使用不同构图。小节编号服务内容层级。不要把整册写成标题、四段文字、公式、同一副栏的重复序列。

## 章节连续性

统计概率章可以安排：事件知识页 → Venn 图解释页 → 条件概率知识与树图 → 贝叶斯频数场景 → 完整计算例题 → 综合辨析题 → 章末关系图。这个序列仅为示例，实际按先修关系与长度安排。

长章连续数页知识后，视内容插入实验、场景总览、完整例题、关系图或综合题。变化帮助理解，不通过无关插画制造翻页变化。不设固定每三页换模板的配额。

## 综合题页

延续教辅“核心素养提升”的功能，大学课程可用“综合理解与应用”等名称。适当标示难度，避免无依据的星级。

典例包含完整题目、分析入口、完整解答、方法归纳和必要条件。副栏可有常见错误、关键观察或替代路径。英语考试保留全部英文解答。不能只给公式套用或省略证明步骤。

## 导航

章节标题、目录、正文编号、答案引用与 PDF 书签使用同一标识。最终分页后生成目录页码。跨栏或大图不切断问题与答案对应关系。两种版本可以页码不同，概念、题目与答案 ID 必须一致。
