# 页型与章节节奏

| 页型 | 主要任务 | 构图要点 |
| --- | --- | --- |
| 正面封面 | 学科识别与全书入口 | 纯白底、局部学科色、黑色标题形、科目标牌、原创人物或数据角色，无宣传口号 |
| 目录 | 展示知识树并通过页码导航 | 专用白底无横线；按kind区分册级横条、章单元强标题和节课明细；双栏或插图侧栏，真实点线与右对齐页码 |
| 知识速查 | 快速检索 | 学科决定的超宽公式、关系、判断流程和图形组合 |
| 册级总览 | 展示知识全貌 | 大型场景或知识地图，分区标注关键联系 |
| 普通知识 | 完整而相关的教学单元 | 定义、解释、例子、逐项对应和必要边界形成短链；或用长推导加例子解释一个核心关系，不按标题数量塞页 |
| 视觉解释 | 展示关系与变化 | 主工作图、局部放大、前后对照与必要解释 |
| 实验或过程 | 器材、操作与观察 | 连续装置图、流程箭头、现象变化、误差说明 |
| 完整例题 | 示范思考与计算 | 完整题目、命名步骤、过程图、解答与解释 |
| 核心素养提升 | 连接多个知识点 | 细蓝框、01/02/03典例、解析、方法、副栏思路 |
| 章末综合 | 恢复章节关系 | 思维图、比较表、时间线、因果链或关联图，配短解释；按学科需要设置 |
| 分章专有词汇表 | 全书末尾快速查词 | 按章分组，仅英文术语与简明中文释义，紧凑双栏 |

按课程内容选择页型，不要求所有学科都有实验页。完整册级任务应考虑总览、知识页、工作图、例题、综合题和速查。章节样本按范围选用。

普通页的标题、颜色和线条形成系列一致性；不同教学任务使用不同构图。小节编号服务内容层级。不要把整册写成标题、四段文字、公式、同一副栏的重复序列。

## 章节连续性

统计概率章先用具体试验讲样本空间、事件与事件关系，再进入条件概率及乘法公式、全概率与贝叶斯公式、基准比例与似然比、独立性及综合应用。每个首次教学链完成后再使用该概念。以上是先修顺序，不是固定页数；短链可合页，长推导可续页。频数表和关系图放在解释需要它的位置，不能把数个首次定义的例子统一推迟到页末。

长章连续数页知识后，视内容插入实验、场景总览、完整例题、关系图或综合题。变化帮助理解，不通过无关插画制造翻页变化。不设固定每三页换模板的配额。

## 综合题页

延续教辅“核心素养提升”的功能，大学课程可用“综合理解与应用”等名称。适当标示难度，避免无依据的星级。

典例包含完整题目、分析入口、完整解答、方法归纳和必要条件。副栏可有常见错误、关键观察或替代路径。英语考试保留全部英文解答，示范例题可保留英文原题。默认成书不另设综合自测、独立答案页和答案词汇。用户明确要求练习册时再建立独立题目系统。不能只给公式套用或省略证明步骤。

## 导航

目录建立双栏密集型、主目录加插图侧栏型两种目标母版，各含第一页和续页。第一页有目录标题，续页沿用简化页眉；目录主框取消正文横线，固定页底趣味条与目录主框分开。完整书至少有一个课程板块，短章节不为凑层级虚构册级内容。父标题与首个子项一起分页，长标题换行后页码位置保持稳定。插图锚定附近outline节点。具体节点外观见 `series-contract.md`；现有脚本支持范围见 `template-workflow.md`。

章节标题、独立知识目录、正文编号与PDF书签使用同一outline标识。最终分页后，根据每个outline节点第一次出现的位置生成目录页码。页面标题只服务当前页面，不能自动成为目录条目。两种版本可以页码不同，概念、outline和典例ID保持一致。

## 图表尺度

正文工作图通常约2–4正文行高，复杂树图或流程图约4–5行，确有精细标签或推理需要时再扩大。微图可横向并排，图前后留白按模板行槽安排，避免一张简单图独占半页。表格采用小内边距，行高由实际文本占用一个或多个网格行决定，不统一设置巨大行高。侧栏漫画沿用原书窄栏相对比例，保持主体与图表的空间关系。

所有页型来自可复用PDF母版。每个正文页在物理页面最底部保留独立浅绿（#F3F7E0）趣味横条，用一至两行深色（#252823）文字排版；该条属于固定页家具，不是正文末尾的知识栏目，不得移到页顶。页码与条中文字互不遮挡。标题使用真实知识名词与简短栏目名，遵循内容语言规范。
