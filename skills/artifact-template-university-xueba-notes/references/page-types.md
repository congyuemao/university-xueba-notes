# 页型与章节节奏

版本7母版和scripts/content_schema.py的PAGE_PROFILES共同定义页型；manifest保留行容量、槽和密度起点。各页型使用实际独立母版或明确组合区域，而不是只写一个名字。普通A4正文34网格槽中最多用31/32槽，正文从第2槽开始；题干、分析、结论和方法也计入容量。

| type | 主要构图和槽 | 内容容量 | 当前校准实例 |
| --- | --- | --- | --- |
| knowledge_dense | 编号知识、定义/性质、紧凑表、手写、教学侧栏 | 至第32槽 | LP变量、基与基本解 |
| knowledge_visual | 工作图、paired图文并置、解释、手写侧栏 | 至第32槽 | 可行域、DP状态 |
| comparison_page | 分类表/对应表与条件、公式、侧栏 | 至第32槽 | 约束翻译 |
| worked_example_page | 细蓝框、大题号、题干、分析、过程、方法 | 至第31槽 | 单纯形完整迭代 |
| application_page | 题号、完整情境、数据表、求解与解释 | 至第31槽 | LP订单、项目分配 |
| core_problem_page | 综合题与知识关联，常见错误和替代路径 | 至第31槽 | 两阶段法 |
| chapter_map | 无主栏横线、有机彩树、公式/小图挂枝、侧栏 | 至第32槽 | 可选；默认关闭 |
| volume_map | 课程树、知识分组、跨章关系、公式/图节点 | 至第32槽 | 可选；默认关闭 |
| process_page | 步骤、轨迹、状态表、枢轴/转移标记 | 至第32槽 | 入基出基、背包表 |
| formula_summary | 公式组、适用条件、比较、手写提醒 | 至第32槽 | 模型与算法速查 |
| glossary | 独立双栏、章标签、英文术语及简明中文 | 31行/栏 | 校准书末 |
| foldout | 594×210 mm四栏，公式/条件/例子组合 | 22行 | 校准折页 |

知识、图表、手写和侧栏是可组合槽，不要求每页塞齐全部组件。每个槽由真实文字与图高度测量；图表大小由可读性决定。简单微图通常2–5行，复杂可行域或网络可扩大。表格按单元格文字计行，不使用巨大固定行高。

## 节奏

先完成教学，再检查章节分布：普通知识、图解、完整典例、综合应用、可选地图、漫画、工作图及手写页比例分别统计。连续3–4页同构图复查；不是硬性每三页换版式。工作图优先于漫画，不能把两者合并计数掩盖缺图。

每个较大章节至少评估一组典例精析/综合应用，短章可合并。默认不另设自测与独立答案页。专题页必须有完整问题、分析入口、计算或证明、结果解释、方法总结；必要常见错/侧栏紧邻。大题号由worked_example.problem_number控制，难度只在有依据时添加。

learning版完整教学；revision版可选公式总结/折页。不能让六十多页承载整本教材而把每种方法压成一句话。

## 动态密度

knowledge_dense建议主栏占位≥65%，图解/比较/过程/题型约≥60%，地图/折页约≥55%；这些是复查起点，不是压字配额。块占位密度不是像素密度，放大一张空图不能算内容充实。

主栏下部和侧栏同时空置时，先合流下一完整教学块，再考虑工作图、小例题或侧栏解释；也可以重分配页型。核心定义与例子保持近邻，禁止用无关装饰填满。

侧栏留白采用章节面积加权指标，每页可不同。既可有侧栏教学密集页，也可有章末书写页；打印内侧装订区始终空白，数字版双栏始终保留。

## 目录

目录独立无横线，kind决定册、章、节、专题、导图及附录样式。两栏按节点测量高度整体平衡，父节点与首子同栏，长标题按层级对齐；相关插图计入布局。最后一页低于配置密度时给告警并人工调整。导航准确与视觉编辑分别验收。

## 并排校准

分别比较两本原书和成品的普通页、题型页、目录；明确启用地图时再比较地图；观察信息层次、图表、侧栏、手写、留白，不以“颜色接近”通过。整章缩略图→阅读尺寸→公式和手写放大→页型统计→连续十页节奏。

## 默认不生成独立地图

只有用户明确要求、信息量充分、能压缩已学内容、且不挤占正文和完整例题时，才生成chapter_map或volume_map。本轮删除两张低信息量地图，将DP应用/阶段/状态/决策表及方法总结迁至“模型与算法速查”。母版页型保留，默认样稿不输出。

worked_example可按分区跨页，续页题号不变。一个step只做一个主要动作，标题与步骤内容一起分页；result和method保持相邻。不得用缩字号、减少解释或将多个步骤塞回一段来适配页数。
