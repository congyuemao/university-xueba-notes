# 四层语言密度

层级由当前教学任务决定，不由打印版或电子版决定。`learning`也包含L4速查；`revision`遇到未教过的内容仍须L1解释。可在块上标`language_level`，这是审稿线索，不是质量证书。

| 层 | 使用位置 | 表达要求 |
| --- | --- | --- |
| L1 首次教学 | 定义、方法引入、公式解释、性质 | 完整句、自然衔接，解释为什么需要；允许教学性重复 |
| L2 概念复现 | 已教概念的再次使用 | 恢复当前所需信息，不重讲整段定义 |
| L3 例题解答 | 完整题目、分析、步骤、结果、方法 | 题干自足；一主任务一步；关键公式独立；交代理由 |
| L4 侧栏与速查 | 手写、旁批、查询表、折页 | 可高度压缩，核心定义和主推理已有正文承载 |

## 同一知识点：最小比值检验

**L1**：增加某个非基变量时，资源剩余量会随之减少。为了保持解可行，我们必须在任何一种资源耗尽以前停止增加。分别算出每条约束允许的最大增加量，再取其中最小值，就能确定哪一个基变量先变为零。

对于等式左侧入基列系数为正的约束，用右端值除以该系数即可得到这个上界。零系数或负系数的行不会按这种方式限制增加，因此不参加此次比值比较。

**L2**：这里仍用最小比值检验。两行给出的上界为4和3，因此第二行首先限制x增加。

**L3**：分成以下两个步骤。

**01 计算上界**

为了保持两个松弛变量非负，分别求两行对x的限制：

\[
s_1=4-x\geq 0\quad\Rightarrow\quad x\leq 4,
\]

\[
s_2=6-2x\geq 0\quad\Rightarrow\quad x\leq 3.
\]

**02 确定出基变量**

取较小上界3。此时s₂先变为0，因此选择s₂出基。

**L4**：只比正系数行；最小比值定出基。

## 同一知识点：状态

**L1**：为了判断后面还能作出哪些选择，我们需要保存当前仍有影响的信息。若每种物品的重量和价值都固定，后续装载只由物品范围与容量决定，就可以用它们描述子问题。

**L2**：此处仍以容量作为状态，物品范围由阶段i表示。

**L3**：乙取1件，容量由7千克减为4千克。下一步计算只使用甲类的子问题F₁(4)。

**L4**：状态只留未来需要的信息。
