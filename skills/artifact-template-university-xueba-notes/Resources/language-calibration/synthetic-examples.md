# 自编大学课程语言样例

以下全部为自编，不是参考书原句；数值仅用于演示，换课程时重新核对知识。

## 基与基变量 · L1

单纯形法每次需要选出一组变量，让方程组直接确定它们的值。对于两个独立约束，我们从系数矩阵中选出两列线性无关的列，这两列组成一个基。与这两列对应的变量叫作基变量，其余变量叫作非基变量。

例如，约束写成x+y+s₁=5、2x+y+s₂=8时，s₁和s₂的两列组成单位矩阵。令非基变量x=y=0，便得到s₁=5、s₂=8。

这意味着尚未生产时，两种资源都保留在库存中。基的选择决定这一轮由方程解出哪些变量；它不意味着这些变量始终为正。

## 阶段与状态 · L1

有些问题需要连续作出几次决策，而且前一步的选择会影响后面的选择。动态规划把决策过程分成若干阶段，每个阶段处理其中一步。为了判断下一步还能怎样选择，我们还要记录当前留下来的关键信息，这些信息称为状态。

例如按物品类别安排装载时，阶段表示已经允许使用哪些类别，容量表示还能装多重。若后续收益和可行选择只由这两项决定，就不必保存全部装载历史。

因此，阶段说明现在进行到哪一步，状态保留仍会影响后面决策的信息。第二遍表述把定义对应到决策任务，具有教学作用。

## 比例性 · L1

在线性规划中，同一种产品的单位消耗在模型范围内保持不变。因此，产量增加一倍，所需资源也增加一倍。利润也按相同方式计算时，总利润与产量成正比，这就是模型中的比例性。

如果采购超过某个数量后能够享受折扣，单位成本就发生了变化。此时应分段描述成本，不能继续使用原来那一条比例关系。

## 一步消元 · L3

为消去其他方程中的x，先从第二个约束中将x解出：

x=4−0.5y−0.5s₂。

将这个表达式代入第一个约束，就能用新的非基变量表示s₁：

s₁=1−0.5y+0.5s₂。

前后两式各有自己的说明，读者能分清正在解出变量，还是正在代入其他方程。

## 向量投影 · L1

我们想知道一个位移在指定方向上产生了多少移动。先用单位向量u表示这个方向，再将位移向量a与u作点积，得到该方向上的有符号长度a·u。

若a·u为负，移动的方向与u相反。要得到投影向量，还需乘上方向u，即(a·u)u；长度与向量因此有不同的表示。
